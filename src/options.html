Startseiten-Weiterleitung

Wenn eine Seite der eingestellten Domain geladen wird und dort der eingestellte Benutzer angemeldet ist, wird auf die Ziel-Seite weitergeleitet. Mehrere Benutzer mit Komma trennen, * = jeder angemeldete Benutzer. Domain mit *. davor gilt auch für Subdomains. Das Ziel kann absolut (https://…) oder relativ zur Domain (/Main/MeineSeite) sein.
