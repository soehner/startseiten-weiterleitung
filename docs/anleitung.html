Startseiten-Weiterleitung

Installations- und Einrichtungsanleitung · Version 1.1.0 · Stand 23.11.2026

1. Wozu dient die Erweiterung?

Die Browser-Erweiterung leitet automatisch auf eine persönliche Startseite weiter, wenn Domain und angemeldeter Benutzer passen. Beispiel: Wer sich auf firma.ariadne.cloud anmeldet, landet direkt auf seiner eigenen Q.wiki-Seite statt auf der allgemeinen Startseite.

Sie funktioniert in Chrome, Edge, Brave, Opera, Vivaldi und Firefox (ab Version 128).

3. Installation

3.1 Chrome, Edge, Brave, Opera, Vivaldi

  1. Die Datei startseiten-weiterleitung-1.1.0-chromium.zip in einen dauerhaften Ordner entpacken, z. B. Dokumente\Browser-Erweiterungen\Startseite. Der Ordner darf danach nicht gelöscht oder verschoben werden.
  2. Die Erweiterungsseite des Browsers öffnen (Adresse in die Adresszeile eingeben):
    BrowserAdresse
    Chrome / Brave / Vivaldichrome://extensions
    Edgeedge://extensions
    Operaopera://extensions
  3. Oben rechts (Edge: links unten) den Entwicklermodus einschalten.
  4. „Entpackte Erweiterung laden“ (Edge: „Entpackt laden“) anklicken und den entpackten Ordner auswählen, also den Ordner, in dem die Datei manifest.json liegt.
  5. Die Erweiterung erscheint in der Liste. Über das Puzzle-Symbol in der Symbolleiste kann man sie anheften, damit das Symbol immer sichtbar ist.
Chrome und Edge zeigen bei entpackten Erweiterungen manchmal einen Hinweis zum Entwicklermodus an. Das ist normal und kann weggeklickt werden.

3.2 Firefox

Zum Ausprobieren (bleibt nur bis zum Neustart von Firefox aktiv):

  1. Die Datei startseiten-weiterleitung-1.1.0-firefox.zip entpacken.
  2. about:debugging#/runtime/this-firefox öffnen.
  3. „Temporäres Add-on laden …“ anklicken und die Datei manifest.json im entpackten Ordner wählen.

Dauerhaft: Firefox installiert dauerhaft nur signierte Erweiterungen. Dafür die ZIP-Datei unter addons.mozilla.org/developers als „Nicht gelistet“ (unlisted) hochladen. Mozilla signiert sie automatisch, danach kann die erzeugte .xpi-Datei per Doppelklick bzw. Drag & Drop in Firefox installiert werden.

3.3 Verteilung im Unternehmen (optional)

Für mehrere Arbeitsplätze lässt sich die Erweiterung per Gruppenrichtlinie ausrollen: Chrome/Edge über ExtensionInstallForcelist, Firefox über policies.json → ExtensionSettings.

4. Einrichtung

  1. Nach der Installation öffnen sich die Einstellungen automatisch (sonst: Symbol anklicken → Einstellungen). Eine Beispielregel ist schon angelegt, aber noch deaktiviert. Sie kann angepasst oder gelöscht werden.
  2. Am einfachsten geht es so: In Q.wiki anmelden, auf das Symbol der Erweiterung klicken und „Regel für diese Seite anlegen“ wählen. Domain und Benutzer sind dann bereits eingetragen.
  3. Für jede Regel folgende Felder ausfüllen:
    FeldBedeutung / Beispiel
    aktivHaken setzen, damit die Regel greift.
    Domainfirma.ariadne.cloud oder *.ariadne.cloud für alle Subdomains
    BenutzerIn der neuen Q.wiki (ariadne.cloud) ist der WikiName eine ID wie Q0123456789abcdef0123456789abcdef. Die Login-E-Mail funktioniert ebenfalls. Den genauen Wert zeigt das Popup unter „Benutzer“. Mehrere Benutzer werden mit Komma getrennt, * steht für jeden angemeldeten Benutzer. Groß- und Kleinschreibung spielt keine Rolle.
    Ziel-Seiteabsolut (https://…) oder relativ zur Domain (/Main/MeineStartseite)
    Wann weiterleiten?Einmal nach dem Login (Standard): Nur die erste Seite nach der Anmeldung wird umgeleitet, danach navigiert man frei. Nach dem Abmelden oder einem Browser-Neustart greift die Regel wieder.
    Jedes Mal bei Aufruf der Startseite: Immer wenn die Startseite der Domain aufgerufen wird, z. B. auch beim Klick auf das Logo.
  4. „Speichern“ klicken. Der Browser fragt einmalig nach der Erlaubnis für die Domain. Bitte bestätigen, sonst kann die Erweiterung nicht arbeiten.

5. Bedienung im Alltag

  • Ein/Aus: Symbol anklicken → großer Schalter, oder Tastenkürzel Alt+Shift+S. Im ausgeschalteten Zustand zeigt das Symbol ein rotes AUS.
  • Diagnose: Das Popup zeigt für den aktuellen Tab die Domain, den erkannten Benutzer und die passende Regel.
  • Merker zurücksetzen: Danach wird beim nächsten Seitenaufruf wieder weitergeleitet. Das ist praktisch zum Testen.
  • Exportieren / Importieren: Regeln lassen sich als JSON-Datei sichern oder an Kollegen weitergeben.
  • Tastenkürzel ändern: Chrome chrome://extensions/shortcuts, Firefox: Add-ons → Zahnrad → Tastenkombinationen verwalten.

6. Fehlerbehebung

ProblemLösung
Es wird nicht weitergeleitetIst der Hauptschalter an und die Regel „aktiv“? Wurde die Domain-Berechtigung beim Speichern bestätigt? Im Popup prüfen, ob der Benutzer erkannt wird und eine Regel passt.
Popup zeigt „kein Zugriff auf die Seite“Die Berechtigung für die Domain fehlt. Regel erneut speichern und die Abfrage bestätigen.
Benutzer „nicht erkannt“Bei Q.wiki tritt das normalerweise nicht auf. Bei anderen Systemen unter Erweitert einen CSS-Selektor oder regulären Ausdruck hinterlegen.
Weiterleitung nur einmalSo ist der Modus „Einmal nach dem Login“ gedacht. Zum erneuten Testen „Merker zurücksetzen“ verwenden.
Firefox: Erweiterung nach Neustart wegSie war nur temporär geladen. Für die dauerhafte Installation siehe Abschnitt 3.2.

7. Datenschutz

Die Erweiterung läuft nur auf den freigegebenen Domains, liest dort nur den angemeldeten Benutzernamen aus und sendet keine Daten nach außen. Die Regeln werden im Browserprofil gespeichert und mit diesem synchronisiert. Die Login-Merker werden beim Schließen des Browsers gelöscht.

Fragen, Fehler und Ideen gern als Issue unter github.com/soehner/startseiten-weiterleitung.
